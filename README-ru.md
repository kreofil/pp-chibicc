# ppchibicc: Процедурно-параметрическое расширения языка C, построенное на базе компилятора chibicc
ppchibicc - это попытка реализовать компилятор языка программирования PPC  поверх компилятора [chibicc](https://github.com/rui314/chibicc) с использованием вайб-кодинга.   Язык PPC является расширением языка программирования C за счет добавления в него конструкций, обеспечивающих поддержку процедурно-параметрической парадигмы программирования (4П). Описание данной парадигмы, а также ее возможностей представлены на сайте [https://www.softcraft.ru/](https://www.softcraft.ru/) в разделе, посвященном [процедурно-параметрической парадигме программирования](https://www.softcraft.ru/ppp/).

Ориентация на chibicc связана с желанием сформировать легковесный компилятор, который можно использовать в учебных и экспериментальных целях. Помимо этого на нем предполагается проверка новых конструкций, которые в последующем будут интегрированы в компилятор [ppclang](https://gitverse.ru/kpdev/llvm-project), реализуемый как расширение компилятора [clang](https://clang.llvm.org/).

Наряду с компилятором в репозитории располагаются примеры, демонстрирующие возможности процедурно-параметрической парадигмы программирования.

В документации приводится описание синтаксиса и семантики расширений языка C, реализованных на текущий момент. Документация и примеры, демонстрирующие возможности PPC, будут расширяться по мере реализации новых конструкций.

Текущая версия компилятора разрабатывается для работы в ОС Linux.

Начальная генерация LLVM IR для небольших программ на C описана в
[руководстве по экспериментальному LLVM backend](docs/llvm-backend-ru.md).

## Сборка компилятора

Проект использует внешнюю сборку CMake. Исходные файлы остаются в `src`,
промежуточные результаты размещаются в `build`, а готовый пользовательский
компилятор копируется в `bin/ppchibicc`.

```sh
git clone https://github.com/kreofil/pp-chibicc.git
cd pp-chibicc
mkdir build
cd build
cmake ..
make -j
```

После успешной сборки компилятор доступен как:

```sh
../bin/ppchibicc main.c -o main
```

Компилятор самостоятельно находит заголовочные файлы проекта в соседнем
каталоге `include`. Для постоянного вызова можно добавить каталог `bin` в
`PATH`:

```sh
export PATH="/path/to/pp-chibicc/bin:$PATH"
```

После этого компилятор можно вызывать непосредственно:

```sh
ppchibicc main.c -o main
```

Для другого CMake-проекта можно указать:

```cmake
set(CMAKE_C_COMPILER ppchibicc)
```

Если Вы хотите использовать другое расширение для файлов, например, `ppc`, то вызов компилятора нужно делат с указанием опции `-xc`. Например:

```
ppchibicc -xc main.c -o main
```

В CMake дополнительно нужно указать:

```
set_source_files_properties(
    ${SOURCE_FILES}
    PROPERTIES
    LANGUAGE C
)
```

## Проверка и очистка

```sh
cd build
make test       # основные тесты stage1
make test-all   # stage1, stage2 и примеры
make clean      # удалить build-результаты, сохранив ../bin/ppchibicc
make distclean  # удалить также build и bin/ppchibicc
```

Корневой Makefile оставлен как короткая оболочка для тех же команд, поэтому
из корня репозитория также можно выполнить `make`, `make test` или
`make test-all`.
